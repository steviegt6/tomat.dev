## docs

platform for hosting hand-written project documentation alongside autogenerated API documentation, TODO

points of reference:

- [vitepress](https://vitepress.dev/);
- [fabric docs](https://docs.fabricmc.net/develop/) using vitepress;

features/goals:

- first-class support for human-authored content (probably mdx pages)
- generated pages should link to the github source somewhere
- various vitepress features:
  - generated outline from headers
  - page authors display from git info
  - sources and resources section
  - useful markdown:
    - codeblocks with tables
    - tables in general
    - footnotes
    - alerts (the colored indentations with INFO, WARNING, etc.; maybe arbitrary but with presets)
- searchbar using a sitemap and maybe more advanced features with algolia idk depends on pricing
- sidebar that can contain both the generated api reference and hand-written documentations (preferably order-customizable)
- host arbitrary api references (I can handle specifics, we just need the layout of the site to support views into both)
  - this should be discussed later because it's secondary
- needs light and dark mode support
- arbitrary support for custom elements usable in hand-authored mdx but probably something we should support inserting into the generated api references
- intelligent cross-linking between the api reference and real documentation
- maybe some history viewer for pages
- ways to maybe differentiate language and product versions so multiple versions of a page can exist?
- ordered and unordered pages so at the bottom some pages can have "next" and "previous" buttons like in vitepress and similar

non-goals:

- in-website page editing
